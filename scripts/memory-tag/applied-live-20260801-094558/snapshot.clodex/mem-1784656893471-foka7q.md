REVIEW DISPATCH RULE (Bogdan, 2026-07-21): use `[agent:team-review] <scope>` (the T24 intent — spawns ephemeral <team>-reviewer-N seat from manifest reviewer role, verdict returns via [agent:review-done] dm, seat auto-archives) as the DEFAULT for cold reviews, NOT a classic Agent subagent. Classic subagent reviewer = fallback only (e.g. reviewer seat blocked on a permission dialog with no operator around — the 07-20 dogfood stall). Scope message still carries: pre-materialized diff path, spec paths, checklist, already-accepted markers. T29a cap (Read/Grep/Glob) applies to the seat automatically.
