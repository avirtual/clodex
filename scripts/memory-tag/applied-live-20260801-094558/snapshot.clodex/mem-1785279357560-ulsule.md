CODE IS PROVEN, PROSE IS MERELY CARED FOR — and that gap is the whole defect surface. 3,067 tests gate the 45% of this repo that is code; nothing gates the 55% that is comment. At read time a comment is indistinguishable from truth, arrives with code's authority, is easier to read, and is written in a confident voice — so agents reason from it IN PREFERENCE TO the code.
