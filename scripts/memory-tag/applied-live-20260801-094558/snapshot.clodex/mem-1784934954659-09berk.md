GORGE-ONCE BRAIN — reproduction guidance (the flag choice, stated as ONE design decision with benefit+cost). Use `--system-prompt-file` (full-replace), NOT `--append-system-prompt-file` and NOT `@file`/Read in msg0. BENEFIT — prefix-position immunity: canonical cache order is tools → system → messages, so a corpus in the system segment sits ahead of msg0 with only (static) tools upstream of it. Nothing above it can move → the preamble band held byte-stable (79,308 tok) across runs while conversation+thinking grew underneath. Via msg0 the corpus would sit BEHIND system prose and CLAUDE.md, so any perturbation there (even a mid-session CLAUDE.md edit) busts the whole corpus write. Also full-replace drops the default CLI preamble entirely → sterile "corpus is the only reference" seat. COST — full-replace also drops the dynamic `# Environment` block (cwd/platform/git/scratchpad), so the agent loses location awareness and will write to read-only FS root / fall back to /tmp. MITIGATION: bake the ABSOLUTE output path into the task prompt. Bonus: no env block = env-independent cache prefix = more cache-stable cross-run. Pair with `--tools "Write"` (hard fence: no Read/Bash → cannot fish off-corpus, must emit GAP: flags instead), `--safe-mode`, FORCE_PROMPT_CACHING_5M, and rm -f the output first (no Read tool = Write's read-before-overwrite precondition is unsatisfiable if the file exists).
