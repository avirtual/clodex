Web-frontend UI parity arc rulings (07-15): browser web client gets a real top MENU BAR (Bogdan ruling — floating ☰ button removed; not a macOS simulation; Edit/View roles skipped, browser supplies them natively). Shortcut web-alternates = Alt family (Alt+T/W/1-9/Shift+[]) at document capture phase, gated on window.__CLODEX_WEB__; accepted cost: shadows readline Meta bindings. Browser notifications = attention/mention broadcasts only (agent-finished has NO companion broadcast — deferred, needs new broadcast or web-host notify fan). Update-available banner in container ruled OUT permanently (image rebuild = the update story; banner would have no action). Drag-drop onto session = net-new feature not parity (desktop lacks it too), parked. Renderer historically had NO window resize handler (Electron never resized under it) — web needed debounced resize→refit. Zoom in browser = native only (JS can't set zoom factor); no per-workspace persistence, approximated by native zoom + resize-refit.
