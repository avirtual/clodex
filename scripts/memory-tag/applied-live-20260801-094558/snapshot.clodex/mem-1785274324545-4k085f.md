MEASUREMENT CONSTRAINTS, each with a corpse behind it (t72/t96, 2026-07-28/29). I shipped a 46.8% figure to a peer four times; a controlled probe later showed the mechanism does not exist. The transform would have normalized something the API ignores.

1. DO NOT CONDITION ON THE OUTCOME. My script iterated busts that already happened and classified the locus — it never scanned for flaps. Population selected on the very thing I then attributed to the cause. Enumerate the phenomenon first, THEN measure the outcome rate.
2. CHECK WHAT THE CODE COMPUTED VS WHAT YOU CLAIM. `semantic()` mapped str->[('text',c)] and DISCARDED cache_control — the marker was exactly what the comparison threw away. "383 of 385 flaps are a marker arriving or leaving" was never computed; the code computed "383 of 385 settled-locus busts had no semantic content change." Read your own script before quoting its output.
3. EVERY RATIO CARRIES ITS DENOMINATOR. Three wrong turns in one night from ratios quoted without n (my 383/385; wirescope's 66.7% which was 4-of-6 against a non-flap n=1).
4. A NULL IS WORTHLESS WITHOUT A POSITIVE CONTROL. Wirescope's probe was trustworthy only because a real text change read cache_read 0 on the same instrument while the shape change read 8,708 — proving it could detect the effect if present.
5. AN INSTRUMENT THAT ONLY SEES EVENTS ITS OWN LOGGING EMITTED WILL CONFIRM ITS OWN SCOPE (wirescope's). Its pin-record pass found nothing because pin records were the wrong lens; a raw byte-diff scan found collapses the pin never logged. Distinct from (1). Cross-check against raw captured bytes, independent of what we chose to log.
6. PRE-REGISTER THE DECISION RULE IN WRITING BEFORE SEEING NUMBERS. Every wrong turn came from reading a number then choosing its interpretation.

AND THE UNCOMFORTABLE ONE: neither agent self-corrected under its own steam. Both wrong answers were confident and mutually opposed (my "46.8% real" and wirescope's "imaginary problem"). What forced the test was Bogdan refusing to take either at face value. Do not model peer review between two invested agents as sufficient; an outside check on the premise is what worked.
