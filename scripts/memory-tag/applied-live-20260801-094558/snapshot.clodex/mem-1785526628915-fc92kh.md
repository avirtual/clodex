SPAWN CWD DETERMINES TEAM MEMBERSHIP — learned 2026-07-31 retiring a probe seat. I spawned `hintprobe` with `cwd:` pointing at the session scratchpad instead of the project root; `clodex-team retire` then refused with "not in the same project (no shared team.json root)". A seat spawned outside the team root is DM-able and works normally, but is unreachable by team tooling — it cannot be retired, and presumably not rostered. Always spawn seats with cwd at the team root (/Users/bogdan/projects/tmux/wb-wrap-ui) even for throwaway probes that touch no project files; give them a scratch path in the task text instead. Also from the same session: the wire route `<team>-<seat>-<hash>` (e.g. clodex-wirescope-7a0ba06f) is NOT the dm target — the seat name is the middle segment only (`wirescope`); dm'ing the full route or a `clodex-` prefixed form bounces.
