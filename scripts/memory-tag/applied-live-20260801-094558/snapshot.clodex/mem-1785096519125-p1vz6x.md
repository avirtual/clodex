A seat spawned with `cwd:` pointing at a git WORKTREE is not a member of the team rooted at the main project dir — team membership resolves by project root via ~/.clodex/teams/*/team.json. Consequences: `clodex-team retire` refuses it ("not in the same project"), it does not show in the team roster, and it cannot receive team tickets. Correct pattern for worktree work: spawn the seat at the MAIN root (so it stays a team member) and instruct it in the ticket to work in the worktree via absolute paths / `git -C`. That is how clodex-hand is configured. Also note two seats rooted at one worktree = two writers on one git HEAD; only ever one writer per worktree.
