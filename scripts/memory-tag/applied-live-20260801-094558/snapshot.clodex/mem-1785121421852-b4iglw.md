Registry migration, PRECONDITION that stop-the-world rests on and that the audit must establish FIRST: are all sixteen write sites reachable from a single quiescent moment at launch?

`legacy-sweep.js` had that BY CONSTRUCTION — it ran before anything else opened the store, single process. The registry is TWO processes. If any write site can fire before or during the sweep, stop-the-world is not stop-the-world; it is a race with a marker file, which is strictly worse than either option because it looks safe.

Verify on the REAL CALL GRAPH, not by design intent. This is the "does it enter the window it names" question one layer up: a migration that claims a quiescent window must be shown to actually have one. Raised by clodex-hand 2026-07-27; it is the precondition, not a detail, and it may invalidate the stop-the-world lean entirely.
