Ticket numbering: the Clodex team registry mints ids independently of the labels I write inside a ticket body. Registry t7 = "correct docs/plugin-plan.md against what shipped" (its body calls itself T8). The out-of-tree `git-branches` acceptance build — the Phase 3 verdict, built by a COLD agent from docs/plugin-api.md alone with zero core edits — was called "T7" in early planning and is NOT registry t7. Always cite registry ids to the hand; use prose names for anything not yet dispatched.
