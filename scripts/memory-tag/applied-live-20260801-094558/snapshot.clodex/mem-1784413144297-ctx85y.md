AMENDMENT to teams design (Bogdan, 07-19, supersedes ruling #2's in-repo half): NO clodex resource inside project files — opening a repo in clodex leaves zero artifacts. team.json lives at ~/.clodex/teams/<team-name>/team.json with required `root` (absolute project path); resolution = scan teams, deepest root containing cwd wins. Task artifacts at ~/.clodex/teams/<name>/tasks/<id>/. Team def is operator-local, doesn't travel with repo (accepted). Seats learn team via added context + clodex-team roster, never a repo file. Any older memory saying "in-repo manifest IS the project" is superseded on the location half; identity is still cwd→root containment.
