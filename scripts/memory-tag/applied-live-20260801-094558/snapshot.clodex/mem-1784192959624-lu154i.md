(2) Codex support: welcome when trivial, must never block or delay a slice; Claude stays first-class (e.g. discovery's disk lens is Claude-only by design). (3) Kill-flow shape SHIPPED in v2.32.0: ✕/Cmd+W = instant archive (entry kept, dimmed row, click resumes), right-click "Delete Session…" + confirm = only record-dropper besides Delete Workspace; archived rows visible-dimmed by default so archive never reads as delete.
