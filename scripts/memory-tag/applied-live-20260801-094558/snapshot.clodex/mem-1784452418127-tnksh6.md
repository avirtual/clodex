DECISION 07-19 (Bogdan lean + designer cold-verified): team role prompts attach via APPEND (--append-system-prompt-file) on top of the full CLI base, carrying only the role delta — NOT replace (--system-prompt-file). Reasons: append composes/chains, leaves the base slot free for an operator's own system prompt, coding roles inherit CLI coding grounding free. My "coding=append, non-coding=replace" was WRONG — CLI base = harness stratum (tools/perms/comms/turn-mechanics, every seat needs) + domain stratum (coding); non-coding seat still needs harness, so it appends + a frame demoting the coding stratum, not replace. Replace = evidence-gated escape hatch, earned per-role only when base actively fights the role AND counter-instruction fails (append composes but can't SUBTRACT); log it as a fork with CLI-base re-sync obligation. Chaining rules: additive specialization not adversarial negation (conflicting layers blend/hedge, no clean last-wins); stack order base→team-block→role→operator (operator wins ties); every layer bills every turn. WATCH: 2+ "ignore the above" in one role prompt = replace-escalation signal. FUTURE (unbuilt): rail: append|replace front-matter + spawn-time mismatch refusal (library mixes rails: trader-* full, clodex-team-* deltas).
