Intent grammar hazard: an `[agent:...]` reference INSIDE a dm/remember body still fires (and terminates the body!) if line-wrapping puts it at a line start — this truncated a task dispatch to hand and fired a garbage [agent:exec] (07-20). RULE: when mentioning an intent inside any body, always escape it as \[agent:...] or put it in a fenced code block. Also: a dm to a cold-idle seat PARKS; a task dispatch must be escalated with [agent:resend <id>] immediately — an idle hand has no "next turn" to ride.
