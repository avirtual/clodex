DISPATCH HAZARD learned the hard way 2026-07-30: never run two subagents concurrently over the same directory tree. I dispatched a doc-move agent and a verifier-port agent both touching plugins/; the doc-move agent ran `git clean -fd` to get an honest suite baseline and destroyed the other agent's untracked plugins/tools/ output. Signature of the clobber: gitignored dist/ survived while merely-untracked plugins/tools/ vanished. Recovery was cheap only because the source scripts lived outside the repo in ~/clodex-brain/plugin/. Rule: either serialize tasks that share a tree, or give each an isolated worktree (isolation: "worktree"). A worker that cleans a tree is behaving correctly in isolation — the collision is the dispatcher's error, mine.
