Team mechanics (Bogdan, 07-22): use the TEAM, not generic subagents. Implementation → clodex-hand (dm). Cold review → the [agent:team-review] INTENT (lead-only; body = review brief incl. spec+diff paths) which spawns the team's reviewer role seat (clodex-team-reviewer prompt, Read/Grep/Glob) and returns the verdict via [agent:review-done]. Do NOT hand-roll reviewer subagents with the Agent tool. Also: [agent:reboot] is a privileged intent (bare reason arg), not an exec. Neither team-review nor reboot has a grammar line in ipc-prompt.js — that surfacing gap is why they get missed; task queued to add gated grammar lines.
