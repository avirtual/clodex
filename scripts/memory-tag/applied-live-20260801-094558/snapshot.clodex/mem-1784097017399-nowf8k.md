EXEC-INTENT NAMING CONVENTION (Bogdan, 07-15): the exec registry (~/.clodex/library/exec/) is global across repos/agents, so defs are named <repo>-<action> — the def is a repo-specific BINDING (fixed cwd) even when the script is generic. wb-wrap-ui defs: clodex-run-tests, clodex-check-syntax, clodex-repo-state (scripts stay generic in scripts/, reusable by other repos' defs, e.g. a future trader-repo-state). Supersedes the old bare names in the token-discipline pin: use [agent:exec clodex-run-tests] etc. Legacy run-tests.json def kept only until Bogdan migrates grants, then delete it.
