PLUGIN DOC-SUFFICIENCY EXPERIMENT — THREE ARMS, RESOLVED 2026-07-28. Bogdan's design. Question: can a third party build a working Clodex plugin from docs/plugin-api.md + docs/plugin-sources.md alone?

ARM A (agentic subagent, full tools, isolated worktree): $10.50, 200 requests, ~1180 LoC, one verb [agent:gh] + 4 sub-commands. Tested live against real repos. Output kept at plugins/github/ in worktree agent-a03f6334419f02eda.
ARM B (subagent, Read+Write only): ~$5.40, 9 requests, 1368 LoC, three verbs. NOT A CLEAN ARM — inherited CLAUDE.md, Clodex harness context, cwd inside the repo. It never read repo source (verified: all 9 tool calls in scratchpad) but "didn't read source" != "doesn't know Clodex".
ARM C (TRUE CLEAN ROOM, the one that counts): ran via ~/clodex-brain/run.sh shape — clean folder, no repo CLAUDE.md, no skills, --system-prompt-file REPLACING the default prompt with the docs, --tools Write, wirescope-routed. $1.34, 3 turns, 293.5s, 979 LoC, subtype=success, node --check passes. Output at ~/clodex-brain/plugin-out/.

THE TWO FINDINGS:
1. BODY-KEY GAP CONFIRMED BY INDEPENDENT CONVERGENCE. Docs never name the property a greedy body arrives on (assigned at session-manager.js:2918-2919; zero occurrences in plugin-api.md). Arm B probes 7 candidate keys; arm C probes 4 (body/bodyText/rawBody/text) and SAYS WHY in a comment. Two agents in different contexts reached the same defensive hack at the same spot. That is a measurement of the docs, not a coincidence.
2. INJECT ONE-LINE RULE IS UNDOCUMENTED AND ARM C SHIPPED THE BUG. In a TUI a newline is a submit. Arm C injects lines.join('\n') up to 7000 chars at :480/:724/:801 — every such reply fragments into many turns. Arm B avoided it ONLY because it inherited Clodex context. Verified the docs never state it: inject(text) documented at plugin-api.md:345/354 as "send text to the agent as if typed", no one-line constraint anywhere in the file.

MY PREDICTION SCORING WAS ITSELF CONTAMINATED. I scored P2 as "inverted/wrong" off arm B. Arm C — the clean arm — CONFIRMS P2. Lesson: never score a prediction against a contaminated arm.

t73 SEVERITY IS NOW MEASURED, NOT ASSERTED: a third party building from docs alone ships a plugin that looks correct, passes syntax, and fragments every reply. Same signature as everything else this week — a CLEAN RESULT, not an error.

HARNESS GOTCHA (cost me $1.06): an ad-hoc `claude -p` run dies at a hard ~303s stream stall on opus-5. ~/clodex-brain/run.sh already documents this and the fix — export API_TIMEOUT_MS and CLAUDE_STREAM_IDLE_TIMEOUT_MS into the PROCESS env, not just settings.json. Also --system-prompt-file strips the dynamic cwd/env sections, so the agent does not know where it is: output paths in the TASK must be ABSOLUTE.
