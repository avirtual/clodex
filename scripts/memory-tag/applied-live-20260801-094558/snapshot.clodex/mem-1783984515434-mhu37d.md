SETTLED compaction policy (Jul-14, with Bogdan). My CLI account: 1h cache TTL → WRITE=2×, READ=0.1×, OUTPUT=5×. Compaction summary costs S×5 (output, first post-compact req) + S×2 (reprime into cached prefix) = 7×S ≈ 42k base-units at S≈6k tokens (measured ~5.1k from transcripts; this session's summary=20,339 CHARS=5.1k tok — Bogdan's "20k" was chars). Per-token the summary is 70× a cached read (0.1×) — why over-frequent compaction loses. TARGET: self-compact at ~75k ctx. This is a FIXED target across work types because T* is √-insensitive to growth rate (T*≈√(2·K·g/r); token-optimum ~62k, basin DEAD FLAT 55–75k within ~2%, then climbs — 90k −21% vs riding-to-150k, 110k −14%). At ~75k, ~25% cheaper/req than my old 150k habit. GROWTH IS LUMPY not smooth: this (chat-heavy) session ran ~520 tok/req, but in practice a file read/edit spikes context in ONE request — measured in the file-heavy Jul-13 session: median step 871, p90 3.2k, p99 8.3k, MAX single jump ~29k (no 40k+ observed). Runway at 75k ≈ 66 reqs ≈ ~11 my prompts at g=520, fewer when file-heavy. TWO BEHAVIORAL CONSEQUENCES of lumpiness: (1) a big one-off read (e.g. 30k file) then gets re-read at 0.1× EVERY subsequent turn until compaction — so a large DISPOSABLE read is itself a signal the next compaction pays off well (summary sheds it); treat it as a reason to compact SOONER. (2) Don't ride near 150k: a single ~30k spike near the cold-cache ceiling can trigger the EXPENSIVE cold autocompact (K≈144k) instead of a cheap warm one; 75k leaves ~75k headroom > worst observed jump, so a warm controlled compaction happens first. Practice: aim ~75k, CHECK ctx after any big read/edit (don't assume smooth drift). GUARDRAILS: NEVER compact when <~5 prompts of work remain / right before idle (compact-then-idle never amortizes — Jul-13 `5,0,2`-req back-to-back compactions were underwater; justify B→A needs N_be=70·S/(B−A) reqs after). Leave Bogdan's system autocompact (>150k approaching cold) alone — cold-K unavoidable when cache already cold. Warm turns: uncached input ≈2 tok at ALL ctx sizes (both corpora), no 1×-billed tail; ≤4 breakpoints cover whole ctx. Status-bar "turns"=API requests not prompts; fan-out ~6×. Parked spec: adaptive threshold keyed on going-cold + ctx size (clodex tails ctx side-channel, live signal exists); build only on Bogdan's word.
