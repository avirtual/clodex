Convention B extension (ruled 07-17, batch 6): a confirm dialog counts as "further UI" — menu items/buttons that open a confirm dialog get the trailing "…" (e.g. "Kill … on peer…", "Restart Clodex…"); fire-and-toast or immediate actions never carry it (e.g. "Rebuild {sandbox}"). Applied uniformly across app menu, tray, and all context menus in polish batch 6. Companion to unit mem-1784164681350-kt48wz.
