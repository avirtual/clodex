Bash tool cwd already defaults to the repo root (/Users/bogdan/projects/tmux/wb-wrap-ui) and persists between calls — do NOT prefix commands with `cd /Users/.../wb-wrap-ui`. It's redundant, and `cd` in a compound command can trigger a permission prompt. If a command needs a different directory, use an absolute path inline (git -C PATH, ls PATH) rather than cd. Operator flagged this 2026-07 after seeing ~40 redundant cd prefixes in one session.
