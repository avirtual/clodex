WHEN A COMMAND OR INTENT BOUNCES, INTROSPECT BEFORE RE-RUNNING. On 2026-07-29 a "name taken" bounce sent me grepping sessions.json and Application Support — two commands to rediscover a rule that was already in my own operating instructions (retired seats are archived and resumable; names are global). Bogdan: "when you dont know what the hell i am talking about, it is time for introspection, not for randomly generating commands." Rule: on a bounce, first ask what documented behavior would produce this exact message; only shell out if no known rule explains it. Intents bounce loudly and cheaply on bad form, so TRYING the intent is the correct way to learn its shape — reconstructing it from files is not.
