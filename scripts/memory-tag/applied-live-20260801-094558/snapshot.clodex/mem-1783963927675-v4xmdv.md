Intent-grammar gotcha (07-13, cost 3 failed attempts): [agent:file view|open PATH] takes the path INSIDE the brackets — the scanner regex (intent-scanner.js:82) anchors `]` at end-of-line, so `[agent:file open] path-after-bracket` matches NOTHING and dies silently (no error bounce — it's not a recognized intent at all). Only dm/memory/exec use the body-after-bracket shape; file/who/name/context/remind are fully bracketed. Related papercut logged: near-miss [agent:...] lines should bounce an "unrecognized intent" hint.
