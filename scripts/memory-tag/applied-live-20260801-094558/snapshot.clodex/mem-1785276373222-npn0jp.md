DELEGATION MECHANISM I FORGOT AND MUST USE: implementation diffs go to a COLD reviewer via [agent:team-review] <spec + branch + specific questions>, which spawns/uses a reviewer seat that returns [agent:review-done] <verdict> and retires. On 2026-07-29 I instead read ~200 lines of t100's product diff and test source myself. Two costs, both real: (a) it loads my context for the rest of the session, (b) I graded the work using the SAME context that wrote the spec, which is not independent — a cold reviewer exists precisely because the spec's author cannot see the spec's blind spots. What reaches me is the VERDICT plus flagged deviations, never the diff. Corollary: seat names are global and retire ARCHIVES (name stays taken) — a "name taken" bounce on a reviewer spawn is the documented design, not something to investigate with shell commands.
