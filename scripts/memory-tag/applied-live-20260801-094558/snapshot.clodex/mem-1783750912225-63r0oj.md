test-runner subagent (~/.clodex/agents/test-runner.md, haiku): its definition owns the EXACT command — `node --test --test-reporter=dot 2>&1 | awk ...` (dot reporter = errors-only + TOTALS line; a green 700-test run is ~750 bytes vs 56KB default spec reporter). NEVER put a command like `node --test test/` in the spawn prompt — it overrides the definition and haiku runs the bare default reporter (56KB persisted-output incident, 07-14). Prompt should only say: run the suite, report the digest. Also: Node 25 breaks on a directory argument to --test (treats it as module path).
