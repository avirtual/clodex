Clodex UI copy conventions (ruled 07-17 overnight, applied app-wide in polish batch 5): (A) Title Case for button labels and dialog headings; sentence case for field labels, hints, placeholders, tooltips, toasts. (B) Ellipsis "…" (single char, never "...") on buttons/menu items that open further UI; tooltips NEVER carry a trailing "…" (et-cetera ellipsis inside tooltip prose is fine). (C) User-facing noun is "sandbox" — "box" is code/comment shorthand only; "Host" means the local Mac (placement selector); peer machines are "the peer"/"the remote machine", never "box" or (except SSH-endpoint contexts) "host". No emojis in new UI; BMP glyphs ▣↗⇄ fine; statusbar emojis 🧠💥🔍🔥❄️ grandfathered pending Bogdan's ruling.
