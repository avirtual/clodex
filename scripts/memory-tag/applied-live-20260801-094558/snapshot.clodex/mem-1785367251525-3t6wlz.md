scripts/vendor-wirescope.sh: the `REF` default is deliberately read out of vendor/wirescope/VENDOR.json, NOT a literal. It used to be hardcoded and drifted to v0.6.37 while the real pin was v0.6.40, so a bare run would silently downgrade the payload three versions and print "vendored wirescope v0.6.37" as a success line. If anyone reintroduces a literal default, that failure returns. Ground truth for the current pin is always VENDOR.json (`ref`/`commit`/`payload_sha256`), never the script and never the RELEASE file alone.
