Cold-reviewer spawns get a wirescope tools allowlist: `[wirescope:tools Read,Grep,Glob]`. Reviewers are read-only — never forward Edit/Write/Bash/Agent to them. They need `git diff` output, so the LEAD pre-materializes the diff to a scratch file at dispatch (`git diff HEAD -- <files> > scratchpad/review-diff.patch`) and points the prompt at it; the reviewer reads code + diff + specs with Read/Grep/Glob only. Also name every spawn with `[wirescope:agent-name <label>]`. Applies to any read-only recon/verify subagent, not just reviewers.
