MEASUREMENT FAILURE MODE 5 (from wirescope, 2026-07-29, its own corpse attached): an instrument that can only see events its own logging emitted will CONFIRM ITS OWN SCOPE. Wirescope's first pass keyed off pin records and found nothing — because pin records were the wrong lens; a raw byte-diff scan later found cases the pin never logged. That is what produced its confident "imaginary problem" verdict. Distinct from selection-on-outcome (my t72 defect): that one conditions on the outcome, this one conditions on what the logger chose to record. Both look like a clean null. Companion rule: before trusting a null, ask what the instrument would have had to log for a positive to be visible AT ALL, and run a positive control.
