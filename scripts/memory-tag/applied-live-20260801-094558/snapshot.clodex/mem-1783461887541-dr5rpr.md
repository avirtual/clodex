Claude CLI mechanism facts (hard-won, don't re-derive): tool gating lever = settings.permissions.deny in generated --settings, NOT --tools; deny arrays union, deny>allow, lower-layer deny sticky; catalog = CLAUDE_TOOLS const. Deny is WIRE-INVISIBLE for cache (schemas still ship) — only --tools + skillOverrides trim wire bytes; gating and cache are different axes. Skill gating: skillOverrides {name:"off"} removes from roster (reclaims tokens); deny Skill(name) is invocation-only. Skill injection: only door is --plugin-dir (session-only plugin, namespaced clodex-skills:<name>). Agent gating: --agents json is additive; deny Agent(name) to force lean. Roster-freeze: skill/agent rosters evaluated at CONVERSATION CREATION; --resume replays frozen roster (changes need /clear); tools are per-invocation, unaffected. Settings merge: our --settings is layer 4 (user<project<local<ours<policy); objects deep-merge later-wins, arrays union. Corner: user-supplied --settings in extraArgs skips hook gen → proxy/deny rules silently absent. Proxy identity: session name = proxy agent name; agent id = clodex-<name>-<nonce> (kept across /clear, new on fresh-create/fork); pickProxyRecord binds on fresh sessionId; context tokens from wirescope, window SIZE from CLI statusline side-channel (.context_window.used_percentage). Codex: resume = `codex resume <UUID>` after top-level flags; hooks flag renamed `--enable hooks` (~0.139). IPC_PROMPT opens with the SETTING, never claims about the model's instructions; sole protocol source of truth in main.js. Intent namespace literal "agent". --dangerously-skip-permissions is persisted per-session, don't strip. Instruction/prompt files are 0600.
