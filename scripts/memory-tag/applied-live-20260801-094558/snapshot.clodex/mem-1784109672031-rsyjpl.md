memory.md discipline: .claude/memory.md is the LIVE THREAD ONLY (uncommitted work, open decisions, in-flight queues) and must stay under ~150 lines / ~8KB. ARCHIVE AT EVERY RELEASE CUT — when a release ships, move its arc to .claude/memory-archive-<date>.md the same day. It is re-read in full after every compact (CLAUDE.md start-of-session rule), so its size is a recurring token cost: at charter size the read is cheap insurance against lossy compact summaries; at 56KB (the 07-15 incident) it was ~15k tokens re-carried per compact. Standing rules belong in this memory store (pinned), never duplicated into memory.md. Archives are forensics-only, never read post-compact.
