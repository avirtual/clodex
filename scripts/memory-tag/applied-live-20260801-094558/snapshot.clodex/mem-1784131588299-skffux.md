Phone-access auth pattern (settled 07-15): remote-wire tokens are stamped by the k8s ingress via configuration-snippet `proxy_set_header Authorization "Bearer <token>"` — phone only does basic-auth, plain bookmarks, no ?token= URLs. Annotations are per-Ingress so paths with different tokens need separate Ingress objects. ingress-nginx v1.14+ needs BOTH allow-snippet-annotations=true AND annotations-risk-level=Critical in the controller cm. deploy/clodex-mobile.yaml is gitignored and holds the secrets; token copies at ~/.clodex/remote-token + work-remote-token. Work laptop's gate self-arms when its Clodex updates past 7e98818.
