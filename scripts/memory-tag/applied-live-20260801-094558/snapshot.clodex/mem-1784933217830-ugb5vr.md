GORGE-ONCE BRAIN — receipt-exact economics (2026-07-25, session 2e17006b, Opus-1M, 79k-token curated corpus via --system-prompt-file, --tools=Write, --safe-mode, FORCE_PROMPT_CACHING_5M). Total $1.355 for a 34KB from-corpus architecture plan. Split: write_paid $0.877 (64.7%) / generation $0.407 (30%) / read_recovered $0.063 (4.6%, @0.1×) / uncached $0.009. KEY: it's "gorge + ONE tool round-trip," not a pure single shot — the Write tool_use forces a req3 that re-reads the corpus at 0.1× (recovered/write ratio 0.071). DECIDABILITY ANCHOR: write_paid is a fixed one-time toll; each amortizing turn adds ~$0.062 read-back, so a multi-turn agent only crosses gorge-once's total cost after re-reading the corpus ~14×. Below 14 re-reads, gorge-once is cheaper. This ratio is THE decision boundary for choosing the pattern.
