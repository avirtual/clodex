Cost rule (Bogdan, 07-22): Fable 5 is expensive — the lead DESIGNS (specs, adjudication, cold-review verdicts), Opus IMPLEMENTS. Every implementation subagent spawned via the Agent tool gets model: "opus" explicitly (never inherit the lead's model); bulk/mechanical loops may go cheaper (haiku). Applies to review subagents too unless the judgment is genuinely subtle. Check that team seats used for implementation (clodex-hand) run Opus, not Fable.
