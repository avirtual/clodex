Emoji ruling SETTLED (Bogdan, 07-17): the color emojis across Clodex UI (statusbar 🧠💥🔍🔥❄️, ⚙ session menu 🛠🧩🤖🔒🕘🔄, popovers/drawers/dialog hints 🧠🛠🧩🤖🔒🕘) are deliberate style — KEEP, never sweep or "fix" them. His only objection was the old large filled-red + button (killed in polish batch 3). The earlier "no emojis in new UI" rule softens to: match the surrounding surface — emojis where sibling controls use them, BMP glyphs (▣↗⇄⚙) where those are the family; never introduce a NEW mixed look.
