PRODUCT PHILOSOPHY (Bogdan, 2026-07-17): Clodex is a tool for pros — never dumb it down. Primary user = Bogdan himself (many sessions, multiple boxes); making HIM efficient is the design center, regular-joe onboarding is a welcome side effect. When friendliness conflicts with the power path, power path wins. "Not everything in your face" = progressive disclosure is fine; feature removal/simplification is not. PR #1's worktrees + session-discovery are onboarding ramps for others, not features he uses (his laptop has tens of thousands of ephemeral agent transcripts, making discovery noise there).
