AMENDMENT to the delegation rule (Bogdan, 07-10): clodex-hand is an OPUS — don't treat him as a junior. Delegate at design level: outcome + real constraints (invariants, house rules, non-goals) + load-bearing context he can't cheaply discover. Do NOT dictate function names, DOM structure, or code idioms — his call, flagged in reports. Review invariants and seams via git diff, not line-by-line re-derivation. Bigger single tasks over sliced ones. Evidence he's earned it: on task #1 (reattach) he caught a race my spec would have baked in (peer-client emits online before refreshing sessions) and pushed back with evidence instead of deviating silently.
