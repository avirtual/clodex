RULE learned the hard way: do NOT edit the hand's worktree while it holds an open ticket. A git worktree shared by two agents is shared mutable state — I installed a plugin and fixed two tests while clodex-hand had ~15 files STAGED for t8. Neither of us could then commit safely: `git add -A` on either side sweeps the other's work into the wrong commit under the wrong message. If I need a change in its tree while it works, SEND it to the hand as a ticket instead of writing it myself. Verify with `git status --porcelain` before touching a worktree an agent owns.
