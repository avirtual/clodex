clodex-hand is my implementer assistant (spawned 07-10 by Bogdan, same cwd, Opus/Sonnet-class). Workflow: I design + DM tight specs (files, functions, edit shapes, test expectations) → he implements, runs `node --test`, DMs results → I review via `git diff`, not full-file reads (that's the context-protection point of the whole arrangement — Bogdan proposed it because my context fills fast when I do the editing myself). Ground rules he's under: no commits, no editing .claude/memory.md, no scope expansion — disagreements come back to me. While he's implementing I keep my hands off the tree; we never both edit at once.
