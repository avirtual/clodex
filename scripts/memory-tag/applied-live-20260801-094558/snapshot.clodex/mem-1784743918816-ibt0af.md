Cache discipline (Bogdan, 07-22): NEVER emit [agent:context compact] voluntarily — it regenerates the summary and busts the prompt cache from ~char 242, re-billing the whole context; a harness /compact may run anyway, doubling the cost. Let compaction happen naturally; rely on memory.md write-ahead for safety. Don't vary early-prompt bytes.
