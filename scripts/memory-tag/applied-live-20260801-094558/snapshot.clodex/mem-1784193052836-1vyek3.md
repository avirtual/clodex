LINEAGE (Bogdan, 2026-07-17): "workbench" = agent-workbench, the old agentic system on the same laptop — Clodex's ancestor. It invented the intent strategy (hence wb-wrap → wb-wrap-ui cwd naming), proved inter-agent communication, has hundreds of intents, spawned many headless agents (the tens of thousands of ephemeral transcripts / 11,860 recent conversations). It grew uncontrollably big and never optimized — "just getting things done in an agentic way" — which is exactly what drove Clodex's creation and its optimization focus. Bogdan decided 07-17 it's probably time to retire it.
