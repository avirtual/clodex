GOTCHA: `[agent:spawn]` and a `[agent:dm]` to the spawned name are NOT atomic. Emitting both in one turn bounces the dm with "no agent named X" — the spawn confirmation arrives afterwards as a separate `[agent:spawn] ok` line. ALWAYS wait for the spawn ok before dispatching the seat's spec, or the seat sits idle with no work while you believe it is running. Caught once on the Phase 3 acceptance build; the bounce notice is easy to miss among tool results.
