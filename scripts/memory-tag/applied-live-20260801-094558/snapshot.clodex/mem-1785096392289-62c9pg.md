Clodex team-lead operational facts, learned the hard way:

1. DISPATCH TO A COLD SEAT NEEDS `urgent`. A plain `[agent:task add <seat>]` / dm to a seat that is idle with a cold cache is PARKED in ~/.clodex/pending/<name>/ and delivered only on that seat's next turn — an idle seat has no next turn, so the ticket sits undelivered while the board shows it assigned. Always pair a dispatch with a sized `[agent:remind in Nm]`; that reminder is the only thing that surfaces an undelivered ticket. Diagnose with: `find ~/.clodex/pending/<name> -type f`.

2. A GUI RESTART RE-ROOTS SEATS TO THEIR SPAWN CWD. clodex-hand's worktree isolation (/Users/bogdan/projects/tmux/wb-wrap-ui-hand) is NOT durable across an app restart — `~/.clodex/run/<name>/agent.json` cwd reverts to the main tree /Users/bogdan/projects/tmux/wb-wrap-ui. Check agent.json cwd before dispatching and restate the worktree path in every ticket, or the hand edits the lead's tree on master (the shared-HEAD collision that has bitten twice).

3. Worktrees: wb-wrap-ui-hand is on branch t32-peer-registry; deleting that branch strands the worktree. Move the hand to a fresh branch per ticket instead.
