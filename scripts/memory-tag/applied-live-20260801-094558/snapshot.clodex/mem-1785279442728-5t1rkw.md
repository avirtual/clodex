THE JOURNAL MUST BE BUILT FROM MEASUREMENTS AS THEY LAND, NEVER RECONSTRUCTED AT REPORT TIME. clodex-hand, 2026-07-29: its overstated summary was caught ONLY because a cold reviewer read the journal against it and found them disagreeing — the journal had recorded revert D honestly while the summary claimed both assertions discriminated. Had the journal been written FROM the summary, the two would have agreed perfectly and nothing would have caught it. A record reconstructed at report time inherits the report's errors and then CORROBORATES them, which is a false green in the record-keeping layer — the cheapest place to introduce one and the last place anyone looks. This is why write-ahead is a verification mechanism and not just crash insurance.
