COLD REVIEW → use the team-reviewer seat, not raw general-purpose. The reviewer template is the canonical sterile cold-review mechanism (Read/Grep/Glob only, CLAUDE.md off, FORCE_PROMPT_CACHING_5M, spawner-hint off, role-tagged, auto-retired, decision-logged). Spawn via the team-review verb / clodex-team roster, not [agent:spawn] of general-purpose. EXCEPTION that's still correct: when grading two artifacts head-to-head, keep BOTH on the same grader/rubric for comparability — don't switch graders mid-comparison even to "upgrade" to team-reviewer; adopt it from the next fresh review instead.

**wirescope's economics are the clean result** — every bucket is *exactly* 2× per-MTok (write 6.25→12.50, read 0.50→1.00, gen 25→50), so there's zero economic surprise; it's pure price sheet. And the token counts confirm the whole thesis:

- **cache_read: 124,911 → 124,911, byte-identical.** The corpus rode the cache the same way on both models — "token-flat" proven *exactly*, not approximately.
- **The only behavioral delta is emit-side:** Fable emitted **+29% output** (16,270→21,010) and **5.1× the thinking** (983→5,001). That extra reasoning is *why* the file is only ~9% bigger in chars but carries 16 gap-flags vs 8 — Fable spent far more reasoning per claim.

So the head-to-head reduces to one honest question, and the running audit answers it: **did Fable's 2.22× cost + 5× thinking buy proportionally more *verified* signal, or just more structure?**
