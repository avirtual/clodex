Clodex env has a `dist-builder` agent + `clodex-skills:dist-build` skill (operator sometimes toggles them off — if absent, that's why). Use the skill for any standalone/test DMG build so build output never loads lead context. release.sh still does its own build internally (fine — run it in a background task). Plain `npm test` is cheap to run directly (~7s, grep two lines).
