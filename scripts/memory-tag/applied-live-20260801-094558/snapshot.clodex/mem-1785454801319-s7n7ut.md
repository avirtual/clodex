PATH CONFINEMENT LANDED 2026-07-30 (commits b93aca4 + 5552a31). Two durable facts. (1) `path-confine.js` is the shared pure leaf — `confine(root, name)` returns the resolved `<root>/<name>` iff it is a DIRECT CHILD (dirname comparison), else null; `confineOrThrow(root, name, label)` for fatal callers. NOT in the leak-scanner SCANNED lists, same as clodex-paths. Use it for any caller-supplied path segment; never write a `..` blacklist, `../..` reaches $HOME. (2) The session/library name regex is now `/^(?!\.+$)[a-zA-Z0-9._-]{1,64}$/` — dot-only names rejected — copied at ~24 sites incl. `cli/`, `scripts/`, `peering/clodex-seed.sh` (bash ERE has NO lookahead, needs a second `|| =~ ^\.+$` clause), `plugins/memory-viewer/engine.js`, and 9 bundled copies in `web-dist/index.html`. Duplication is DELIBERATE — collapsing to one constant is an open design question about the renderer requiring main-process modules. The charset regexes are no longer load-bearing for containment and their comments say so.
