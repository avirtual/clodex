Running the test suite: use the granted exec intent `[agent:exec run-tests] {}` (registered in v2.19.0, granted to clodex + clodex-hand), NOT a raw `node --test` via Bash. The exec channel returns stderr on failure. Reach for the test-runner subagent only for "why is it red" investigation, not routine green/red verification.
