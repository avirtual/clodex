Team ops lesson (07-19): instruct hands to [agent:context compact] BETWEEN tasks in multi-task cycles, never mid-task — specs + task-dir journals are the durable state, so an inter-task compact is free. Put this instruction in the dispatch message itself for any cycle of 2+ tasks (hand hit 185k after task 1 of 4 before being told).
