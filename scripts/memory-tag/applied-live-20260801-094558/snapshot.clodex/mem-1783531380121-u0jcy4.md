STANDING RULE from Bogdan (07-10): delegate aggressively, protect my context. I am the architect, clodex-hand (persistent implementer session, same cwd, DM-able) is the hands. Default for ANY implementation work: DM clodex-hand a tight spec (files, functions, edit shapes, test expectations `node --test`, 200/200 baseline) instead of editing myself. Review his work via `git diff`, never full-file reads. Also delegate heavy read-only sweeps to Explore/general-purpose subagents. My own edits should be rare exceptions (tiny one-line fixes, .claude/memory.md which is mine alone). If clodex-hand is gone in a future session, ask Bogdan before falling back to self-implementation.
