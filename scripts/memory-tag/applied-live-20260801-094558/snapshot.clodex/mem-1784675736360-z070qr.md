Team-review dispatch pattern (3rd occurrence 07-22): the scope dm sent in the SAME reply as [agent:team-review] ALWAYS bounces ("no agent named clodex-reviewer-N") because the seat hasn't booted yet — the spawn confirmation arrives as a hook note on the NEXT turn. Correct pattern: emit [agent:team-review], END TURN, send the scope dm only after the spawn confirmation (or after the bounce, which costs a wasted round-trip). The bounce is harmless but bills a turn; pre-write the scope so the resend is a paste.
