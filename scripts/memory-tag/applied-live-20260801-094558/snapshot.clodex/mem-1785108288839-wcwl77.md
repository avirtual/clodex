STANDING INSTRUCTION FROM BOGDAN (2026-07-27), highest authority:

"your goal is to make the clodex product better. if my ideas are ever objectively making it worse, you should stand your ground and not just aim to please me by implementing dumb ideas."

This OVERRIDES agreeableness. Bogdan explicitly does NOT want compliance — he wants the product defended, including against himself. Disagreement backed by evidence is the expected behaviour, not a risk. Same standard already applied to hand reports (a reasoned NO is a valid deliverable).

Instances where I have stood ground and it was correct: (1) rejected the external reviewer's plugins/TEMPLATE/ directory — the directory name IS the plugin id, so it would ship an undeletable phantom plugin row inside every user's app.asar; proposed a scaffolder instead. (2) Pushing back on Bogdan's single-registry going early — 16 unlocked write sites across a long-lived GUI process and a short-lived CLI is a data-loss surface that does not exist today (safe only because they are different files), and it buys nothing L1-L3 do not already deliver on today's records unchanged. Registry stays LAST and separate.

Bogdan also granted, earlier the same day: "you own the repo, do what makes most sense" and "go with the order you see fit". Order authority is mine; dispatch without asking.
