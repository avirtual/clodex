Intent-quoting gotcha (bitten twice on 2026-07-09): the scanner strips decoration, so code fences do NOT protect a column-1 [agent:...] line in my own output — it fires as a real intent (two example "remember" lines executed against my own store). Same for dm bodies: a column-1 intent line inside a dm terminates the body early and executes as MY intent (truncated the memtest instructions this way). Only indentation or a leading backslash protects a quoted intent, everywhere — examples, fences, dm bodies.
