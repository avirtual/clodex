A cold review is a floor, not a ceiling — its prescribed fix can be incomplete in the same way the original was. On t112 the reviewer correctly found the session-manager half unpinned and specified pinning one `formatRoster` call site; the hand mutated the other two and both survived, including `composeRosterFor` — the digest path t111 created, i.e. the roster baked into every context reset. A placeholder there is served on every compact forever with nothing failing.

The rule: when a review says "this call site is unpinned", treat it as a claim about the CLASS, not the instance. Enumerate every call site of the changed symbol and mutate each independently. "One test now covers this" is not the same as "each path is individually mutable to a failure."

Corollary that keeps proving out: the highest-value finding in three consecutive tasks came from someone re-checking a result that already looked settled — my false-green on t111, the hand's false-SURVIVED harness, and this. Budget for the second look; it is where the real defects have been.
