CONSOLIDATION'S FIRST LIVE RUN INVERTED THE ONE CASE WITH A KNOWN ANSWER (2026-07-31, scratch copy, nothing applied). The contrarian agent EXISTS (live on the roster). mem-1784506828448-5c0ues, the newer unit correctly recording that, was ARCHIVED as expired. mem-1783524813485-l7u6nx, the omnibus pin carrying the FALSE clause "contrarian is RETIRED... do NOT propose consulting it", was KEPT. The store would have emerged asserting the opposite of reality, with pin authority.

WHY, and this is the generalizable part: BOTH units are MIXED, in opposite directions. l7u6nx is mostly-true with one false clause; 5c0ues is mostly-stale ticket bookkeeping with one durable correction inside it. A unit-level verdict resolves each by its MAJORITY content, so the transient majority in 5c0ues outvoted the durable clause and the true majority in l7u6nx protected the false one. The `partial` verdict covers only the first shape (keep the unit, name the rotten clause) — there is NO verdict for "archive this EXCEPT the part that must survive." Mixed units are the dominant shape in this store, not an edge case.

(3) 16 of 111 PINNED units archived in one pass, 45 of 194 total (23%) — a rate no unsupervised pass should have over pins.

METHOD RULE THAT SAVED THIS: I ran against a scratch COPY and checked the known-answer case FIRST. A green pipeline over unknown data cannot detect this class — only a case whose answer you already know can.
