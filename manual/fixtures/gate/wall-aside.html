Get started with Kibana

Prerequisites

  • An Elastic Stack deployment or Elastic Cloud Serverless project with Elasticsearch and Kibana. Don't have one yet? Start a free trial.

  • Sample data loaded from the home page.

Open Kibana and select Discover to explore the sample documents, then build a dashboard from the saved searches.

Each visualization can be added to more than one dashboard and shared by link.
