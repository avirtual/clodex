Get started with dashboards

Dashboards collect visualizations, saved searches and maps in one place so your team can watch the same numbers. This guide walks through creating your first one.

Start a free trial

Step 1: add data

Open the integrations page, pick the sample web logs, and wait for the import to finish before you continue.

Step 2: create a dashboard

Open Dashboards, click Create dashboard, then add a panel from the library. Save it with a name your team will find.
